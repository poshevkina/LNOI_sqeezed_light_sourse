# Прямой трёхмерный ответвитель LNOI

Исходный локальный файл `lnoi_coupler_3d.mph` открыт как источник для рабочей
копии `lnoi_coupler_3d_ports.mph`. При первом запуске с `--solve` Python
собирает копию с четырьмя пользовательскими портами и одним Frequency Domain.
Поперечная область приведена к 2D-модели. Геометрия прямого участка, материалы
и Beam Envelopes с двумя попутными волновыми векторами сохранены.

```powershell
python -m studies.coupler_3d --dry-run
python -m studies.coupler_3d --solve
python -m studies.coupler_3d
```

`--pilot` ограничивает расчёт зазором 0,8 мкм и сохраняет пилотный отчёт
в `results/studies/coupler-3d-pilot`. Полный сценарий проверяет 7 и 14
продольных слоёв на пилоте. При расхождении выше допуска результат
помечается как несошедшийся. Новый расчёт на 28 слоях возможен только с
явным `--check-28 --solve`. Если кэш на 28 слоях уже есть, он пригоден для
сравнения и при обычном запуске. После приёмки пилота сценарий запускает
зазор 1,6 мкм. На каждый зазор рассчитывается возбуждение
левого волновода отдельно для quasi-TE и quasi-TM.

Кэш `field_maps/coupler3d_…/sections.npz` содержит фактическую ось расстояния
от входа, мощности в левой и правой половинах сечения и `|E|²` на нескольких
срезах. В исходных координатах вход находится при z=200 мкм, выход при z=0.
Отчёт использует расстояние от входа. Положительная мощность направлена к
выходу. Вид возбуждения, хеши исходных 2D-карт, число элементов, число
степеней свободы и время сохранены в кэше и сводке исследования.

## Одна точка на выбранной сетке

Сценарий [coupler_3d_single.py](../../../studies/coupler_3d_single.py)
по умолчанию выбирает quasi-TE, зазор 0,8 мкм и 16 продольных слоёв.
Параметры `LAYERS`, `GAP_UM` и `FAMILY` находятся в начале файла.
Можно передать их в терминале как `--layers`, `--gap` и `--family`.

```powershell
python -m studies.coupler_3d_single --dry-run
python -m studies.coupler_3d_single --solve
```

Задача с `--solve` считает только выбранную точку. Сводка подхватывает
готовые результаты на 7 и 14 слоях для тех же зазора и поляризации.
Без `--solve` сценарий только читает кэш. Ширина и длина волны берутся
из 2D-отчёта, поскольку входные супермоды рассчитаны для конкретной геометрии.

## Диагностика поля по всему ответвителю

Новые случаи дополнительно сохраняют два трёхмерных массива в `sections.npz`.
`electric_squared_volume` хранит квадрат модуля полного электрического поля,
`longitudinal_flux_w_m2` — знаковый поток Пойнтинга в направлении от входа к
выходу в Вт/м². Порядок осей обоих массивов — `[z, y, x]`, оси в микрометрах
лежат в `z_um`, `y_um` и `x_um`. `z_um` означает расстояние от входа.
Два массива `float32` на 103 сечениях по 256 × 200 отсчётов занимают
около 42,2 МБ до сжатия. Это разрешение выборки готового решения.
Для интегральных мощностей используется прежняя сетка 152 × 125 и двойная
точность. Сетка элементов COMSOL при увеличении разрешения карт не меняется.

После сохранения каждого решённого случая `diagnostics.png` появляется
в его папке `field_maps/`. В общем отчёте `*_diagnostics.png` показывает продольные срезы (xz) и (yz),
в том числе слабое поле на логарифмической шкале и знак потока. Сетка по
длине с основным шагом 2 мкм подходит для обзора перекачки и крупных пятен.
Фаза, комплексные декартовы компоненты и решённый MPH в этом формате не
сохраняются.

Старые кэши остаются пригодны для анализа пяти поперечных карт и кривых
мощности. В сводке они помечены `five_slices`. Если понадобится объём
для старого рассчитанного случая, запусти сценарий с `--solve --refresh-fields`.
Он пересчитает случаи без объёма или с более редкой сеткой карт. Например, для пилота:

```powershell
python -m studies.coupler_3d --pilot --solve --refresh-fields
```

## TE и TM на одинаковой сетке

```powershell
python -m studies.coupler_3d_compare --dry-run
python -m studies.coupler_3d_compare --solve
python -m studies.coupler_3d_compare
```

По умолчанию это зазор 0,8 мкм и 16 слоёв. `--solve` запускает quasi-TE,
затем quasi-TM. Обычная команда строит отчёт из кэша, включая готовые 7 и 14 слоёв.
Зазор и число слоёв меняются через `--gap` и `--layers`.

В `coverage.csv` отмечено, где есть только пять сечений и где есть объём.
На общих графиках видны передача, разница сеток, баланс потока и сравнение
TE/TM при одинаковом числе слоёв. Для объёмных данных добавляются атлас сечений,
проекции поля и потока, положение центра поля, эффективная площадь и
сравнение двух сеток интегрирования потока. Доля локального обратного потока
в этом отчёте интегрируется внутри сечения. Для коэффициента отражения
потребовалась бы проекция на выходящие портовые моды.
