# Прежние исследования

Ноутбуки сохранены для сверки методики и параметров. Новые отчёты открываются в основном ноутбуке проекта. Команды ниже запускаются из корня репозитория по сохранённым данным COMSOL.

- [Сравнение полиномов](fit-effect.ipynb) — аппроксимации Re(n_eff) по угловой частоте, степени 1–6, производные, исключение внутренних точек, JSI и K для всех PUMP-ветвей при 2000 фс. Повторение — python -m studies.fit_effect.
- [Без пространственной классификации](unclassified.ipynb) — полином шестой степени по ω, импульс 2000 фс, JSI и K по ширине для локальных PUMP-рангов. Ранг задаёт порядок Re(n_eff) в опоре отдельно для каждой ширины. Повторение — python -m studies.unclassified.
- [Одна длительность](spatial-single.ipynb) — signal TM0, idler TE0, полином шестой степени, 2000 фс и полуширина окна 0,0025 рад/фс. Отчёт включает JSI, K, маргинальные спектры, FWHM и проверку поляризации накачки в интервале с 99% JSI при пороге примеси 10%. Повторение — python -m studies.spatial_single.
- [Серия длительностей](pulse-series-6d91908.ipynb) — исторический снимок основного ноутбука из коммита 6d91908. Длительности 250–2000 фс с шагом 250 фс, 2000 точек на частотную ось и полуширины окон от 0,015 до 0,0025 рад/фс. Графики K от ширины и длительности, аудит гибридизации для каждого импульса. Повторение — python -m studies.pulse_series.
- [Совмещённая конфигурация](run_config.json) — настройки прежнего запуска COMSOL и обработки одной командой. Для отдельного расчёта полей используется [текущая конфигурация COMSOL](../run_config_comsol.json).
